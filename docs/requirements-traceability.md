# Requirements Traceability Matrix — SIH Problem Statement 26262 & APH Alignment

**Problem Title**: Integrated AICTE Approval Workflow Automation, Compliance Monitoring and Alert Management System (PS 26262)  
**Primary Regulatory Source**: AICTE Approval Process Handbook (APH) 2024–25 to 2026–27 (Legal Document as per AICTE Act 1987)

---

## 1. Requirement Classification Taxonomy
Every requirement is categorized under one of the four mandatory audit labels:
- `[VERIFIED-SOURCE]`: Fully verified against primary regulatory statutes (AICTE Act 1987 / APH 2024-27) or official system architecture.
- `[IMPLEMENTED-TESTED]`: Verified against source, implemented in codebase, and validated by passing unit/integration tests.
- `[PROPOSED-BEHAVIOR]`: Engineering design proposed for future implementation stages; pending statutory code implementation.
- `[BLOCKED]`: Dependent on external data source, hardware access, or authoritative government portal API.
